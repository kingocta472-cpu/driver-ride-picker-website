For the best Driver Ride Picker background performance, please enable the following settings on your Android device.

Enable Driver Ride Picker in Android Accessibility settings so the app can detect supported ride information and perform its permitted ride-selection assistance functions.

2. Display Over Other Apps

Allow Driver Ride Picker to display over other apps so the ride assistance interface can remain available while you use supported ride applications.

Allow Driver Ride Picker to run in the background without restrictive battery-saving limits so background ride detection can work more reliably.
